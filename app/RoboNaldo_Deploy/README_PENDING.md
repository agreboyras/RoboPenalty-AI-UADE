# Directorio parcial de recursos

Incluye SOLO 35 meshes de procedencia Unitree ROS BSD-3-Clause, su licencia exacta LICENSE-Unitree-ROS.txt y cinco __init__.py vacios generados. No se incluyo codigo sustantivo de Deploy/TP07, ONNX, NPZ ni XML pendientes.

El instalador prepara solo lo autorizado; los 26 pasos restantes estan en docs/pending_resources.json de la raiz. external_sources.json conserva las fuentes fijadas y los hashes. La carpeta no habilita una partida incompleta. No usar git add -f para incorporar recursos pendientes ni parches derivados.

Una instalacion local puede completar los 26 archivos mediante scripts/importar_deploy.ps1 desde una copia adaptada obtenida legitimamente. Los importados se mantienen excluidos de Git. Este README describe el contenido distribuido, no los archivos privados que pueda importar cada usuario. Ver docs/IMPORTACION_LOCAL.md en la raiz.
